## About Me

Java, JSP/Servlet, MySQL, Oracle DB 기반 프로젝트를 경험하며
웹 시스템 개발과 유지보수 업무에 필요한 기본기를 쌓고 있습니다.

팀 프로젝트가 끝난 뒤 실행되지 않던 두 프로젝트를 혼자 다시 살렸습니다.

- **everyWEAR (JSP/Servlet 쇼핑몰)** — 버전이 서로 다른 작업본을 비교해 Java 21·Tomcat 9 기준으로 복구하고,
  평문 비밀번호·결제 금액 위조·권한 없는 데이터 변경 같은 보안 문제를 고쳤습니다.
- **알고먹자 (Java Swing)** — macOS 환경에서 DB 연결 오류, 누락 테이블,
  DAO와 DB 스키마 불일치, 화면 흐름 문제를 개선했습니다.

현재는 Java 웹 개발, SI/SM, 전산운영, 시스템 유지보수 직무를 중심으로
운영 중인 시스템을 안정적으로 이해하고 개선하는 개발자로 성장하고자 합니다.

> 더 자세한 프로젝트 경험은 포트폴리오에서 확인하실 수 있습니다.
